    Every feature works during the trial. After it, discovery stays free and control needs a licence.

    Paste your licence key into the app. It needs no internet, so it works on an air-gapped network.

Questions

Do I need an internet connection?

No. Both tools run entirely on your local network and check licences offline. Nothing is sent to the internet, including your device inventory. They are made for isolated, air-gapped broadcast networks.

What do I need to install?

Nothing. Each download is a folder that already includes the runtime. Unpack it anywhere, then double-click the launcher on Windows or run the start script on Linux. It needs no administrator rights and no Node.js.

Which platforms are supported?

Windows 10 and 11 (64-bit), and Linux on x86-64 and ARM64: a server in the machine room, a laptop, or a Raspberry Pi. On a Linux server it can run as a service; the read-me in the download shows how. A build for macOS is planned; get in touch if you need one.

Who can use it?

Everyone gets their own account. The first start asks you to create the administrator, on the computer the tool runs on; the administrator then adds the others, each with a role, and resets a forgotten password.

How does the trial work?

The first launch starts a 14-day trial with every feature. After it ends, discovery and diagnostics keep working for free, and the control actions (routing, automation, reservations) work again once you activate a licence key.

How is it licensed?

You buy a licence key, paste it into the app, and the app checks its cryptographic signature offline. Keys are per machine (Pro) or per facility (Site), perpetual or annual.

Can I run it in a critical, on-air environment?

The tools are professional utilities: always check routing and control actions in your own environment first. The licence agreement included with each download has the full terms.
