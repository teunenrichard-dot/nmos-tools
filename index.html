Questions

FAQ

Do I need an internet connection?
No. Both tools run entirely on your local network and validate licences offline. Nothing — including your device inventory — is sent to the internet. They're designed for isolated, air-gapped broadcast fabrics.
What do I need to install?
Nothing. Each download is a self-contained folder that already includes the runtime. Unzip it anywhere and double-click the launcher — no admin rights, no Node.js, no dependencies.
Which platforms are supported?
Windows 10/11 (64-bit) today. macOS and Linux builds are on the roadmap — get in touch if you need them.
How does the trial work?
The first launch starts a 14-day trial with every feature unlocked. After it ends, discovery and diagnostics keep working for free; the control actions (routing, automation, reservations) unlock when you activate a licence key.
How is it licensed?
You buy a licence key, paste it into the app, and it's verified offline against a cryptographic signature. Keys are per-machine (Pro) or per-facility (Site), perpetual or annual.
Can I run it in a critical, on-air environment?
The tools are provided as professional utilities — always validate routing and control actions in your own environment first. See the licence agreement included with each download for the full terms.
